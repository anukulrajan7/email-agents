# Status, 14 Oct 2026

Post Room is agentic for its core jobs and cheap to run, but not yet fully generic: HR is still the built-in default
until milestone M1 (packs) lands.

AI runs automatically only on new mail; older mail is read when opened.

## Fully agentic?
Partly. Core loop exists (goals, tool choice, memory, approvals, self-checks, budgets, traces). Missing: agents for more
than two jobs, specialist desks, plain-English workflow builder (M6), golden-set evals before more autonomy.

## How the agent works
1. Email arrives → labelled + summarised cheaply.
2. Client requirement → Requirement agent case; needs reply + auto-reply on → Inbox agent case.
3. Agent works step by step with tools, writing in the mailbox owner's voice.
4. Sends/submissions wait in Agents → Waiting for you, unless the owner's profile allows routine replies.
5. Anyone can ask Meera by voice or text.

## Generic or HR-centric?
Still HR-centric by default. M1 (packs: General default; Support, Sales, Finance, Personal, HR optional) is half built
and resumes when the AI usage limit resets. Then: specialist desks, versioned workflows, plain-English builder,
goal-first onboarding (see docs/universal-plan.md, docs/specialist-agents.md).
